# FurShield demonstration script

Use a 1440×900 browser window, then repeat the key public and owner screens at 390×844 to demonstrate responsive behavior.

1. Open the landing page and show public navigation, the care-ledger concept, vets, care cards, adoption preview, footer, and responsive menu.
2. Open Care Library. Search for “vaccination” and use category filters. Expand a guide.
3. Open Find a Vet. Search by specialty and location, then show an appointment call to action.
4. Open Adoption and filter by species.
5. Open Products. Filter categories, add the same item twice, remove one, and show the changed cart total. Explain that payment and delivery are excluded.
6. Open About and Contact; show the live map.
7. Log in as the owner. Show dashboard metrics, Mochi’s profile, the health timeline, editing, a new vaccination/due date, and a signed gallery/document upload.
8. Request an appointment and show cancellation/status controls. Open adoption interest, notifications, and ratings.
9. Log out and log in as the veterinarian. Show profile/availability, schedule approval/status, booked-pet authorization, and structured treatment notes.
10. Log out and log in as the shelter. Add an adoption listing, add feeding/grooming/medical care, review interest forms, and update an adoption status.
11. Return to the affected owner account and show the persisted notification.
12. Finish with mobile views and keyboard focus indicators.

Target duration: 7–10 minutes. Record at 1080p and export as MP4.
